# 第一次用 USDT 付云服务的完整过程

用 USDT 付款本身不难，出问题基本都是因为网络选错、金额不对、订单过期。下面按实际操作的先后讲一遍。

## 准备：手里要有 USDT，还要留够手续费

USDT 可以在交易所买，买完提到自己的钱包，或者直接从交易所提币付款。注意两点：

- 链上转账要手续费，TRC20 的手续费一般用 TRX 支付，钱包里要留一点 TRX；
- 交易所提币时，手续费可能从提币金额里扣，实际到账会少一点。

还没买过的可以先看 [如何购买 USDT 并通过 TRC20 提币](https://www.clouddage.com/resources/buy-usdt-and-withdraw-trc20)。

## 认清三条常见网络

| 网络 | 地址长相 | 说明 |
| :--- | :--- | :--- |
| TRC20（波场） | 以 `T` 开头 | 用得最多，手续费较低 |
| ERC20（以太坊） | 以 `0x` 开头 | 手续费随以太坊网络拥堵变化 |
| BEP20（BNB Chain） | 以 `0x` 开头 | 地址和 ERC20 长得一样，最容易混 |

订单页让你用哪条链，就只用那条链转。ERC20 和 BEP20 地址格式相同，钱包不会拦你，转错链的钱很难追回。

## 下单：先看懂订单页再付款

以云大哥为例，下单流程是选平台、选开户或充值、填到账金额和邮箱，核对页会算出应付 USDT。订单页上要看的是这几项：

1. 收款网络；
2. 收款地址；
3. 应付金额（精确到小数）；
4. 付款有效期。

每个字段是什么意思，可以看 [看懂订单页的每个字段](https://www.clouddage.com/resources/how-to-read-order-page)。报价怎么算、完整的四个阶段，见 [报价与办理流程](https://www.clouddage.com/pricing)。

## 转账：复制，不要手打

- 地址用复制粘贴，粘贴后核对开头和结尾各四位；
- 金额按订单页填，确保到账数不少于应付数；
- 在有效期内付完，过期的订单不要再往那个地址转。

只认订单页上的地址。任何人私下发给你的「新地址」「备用地址」都不要用。

## 转完：留好交易哈希

转账成功后，钱包或交易所会给出交易哈希（TxID）。把它和订单号存在一起。TRC20 的交易可以在 TRONSCAN 查，ERC20 的在 [Etherscan](https://etherscan.io/) 查。订单状态一般在链上确认后自动更新，长时间没变化时，带着订单号和交易哈希去联系客服。
