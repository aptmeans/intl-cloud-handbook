# 充值前后各核对一遍

充值出错，最常见的是填错了账号。钱进了别人的账号，基本要不回来。所以付款前、到账后各花两分钟核对，很值。

## 五个平台认的账号标识不一样

| 平台 | 充值时要提供 | 在哪里找 |
| :--- | :--- | :--- |
| 阿里云国际 | UID（账号 ID） | 控制台右上角头像菜单 |
| 腾讯云国际 | 账号 ID | 账号信息页，见 [账号概述](https://www.tencentcloud.com/document/product/378/80429) |
| AWS | AWS 登录账号 | 交付信息里；12 位账号 ID 的位置见 [View AWS account identifiers](https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-identifiers.html) |
| Azure | 订阅信息 | 由顾问确认 |
| Google Cloud | 结算账户信息 | 由顾问确认 |

各家标识的截图位置，[充值前先找准账号标识](https://www.clouddage.com/resources/find-account-id-before-top-up) 里有逐家说明。

## 付款前核对三件事

1. 账号标识从密码管理器里复制，不靠记忆手打。
2. 核对页上的到账金额是你想要的数，应付 USDT 你认可。
3. 收款网络和地址只来自订单页。

还要注意一点：渠道充值通常只受理在同一渠道开的账号。比如云大哥的 [充值说明](https://www.clouddage.com/top-up) 写明只受理在云大哥开通的账号，核验不通过不会生成付款信息，这样也能防止充错号。

## 到账后对账

- 订单状态变成已支付后，登录云平台的费用中心，看余额变动和订单金额是否一致；
- 余额变化的截图、订单号、交易哈希，三样存在一起；
- 月底对账时，用这三样就能把每一笔对上。

充值只增加余额，不会改动已经在跑的实例、IP 和配置，不用担心业务中断。

## 对不上怎么办

先别重复付款。整理好订单号、交易哈希、费用中心截图（账号 ID 可以打码一部分），再联系办理方。重复付款只会让对账更乱。
