# 做东南亚和香港业务：阿里云国际还是腾讯云国际

两家都是国内厂商的海外站，界面和产品名大同小异，很多人纠结半天。其实按业务类型看，差别还是挺清楚的。

## 先确认一件事：海外站和国内站是两套账号

阿里云国际（alibabacloud.com）和阿里云中国站（aliyun.com）账号不通用，腾讯云国际（tencentcloud.com）和腾讯云中国站（cloud.tencent.com）也一样。国内站的余额、代金券和工单都带不过来，海外站按美元计费。机器放在香港或海外地域，一般不用做 ICP 备案。

## 按业务类型选

| 业务 | 更顺手的一家 | 原因 |
| :--- | :--- | :--- |
| 跨境电商独立站、ERP | 阿里云国际 | 东南亚节点多，和电商生态配套多 |
| 手游、H5 游戏出海 | 腾讯云国际 | 游戏服务器、联机对战和反外挂方案成熟 |
| 直播、短视频、音视频通话 | 腾讯云国际 | 实时音视频和直播 CDN 是强项 |
| 普通企业官网、SaaS 后台 | 两家都行 | 看哪边折扣合适、团队更熟 |
| 需要中国内地和海外互通 | 两家都要评估 | 都有跨境专线类产品，按线路实测再定 |

## 机房怎么挑

同在东南亚，新加坡节点的网络最均衡，印尼、泰国、越南的用户比例高的话，再考虑雅加达、曼谷等本地机房。开机器前最好先在目标地区找几台设备测一下延迟，比看宣传图靠谱。更细的东南亚对比可以看云大哥资料库里的 [腾讯云与阿里云东南亚节点怎么选](https://www.clouddage.com/resources/tencent-vs-alibaba-southeast-asia)。

## 两家各自的账号标识

后面充值、提工单都会用到，先记下来：

- 阿里云国际：UID，也叫账号 ID，在控制台右上角头像菜单里能看到。
- 腾讯云国际：账号 ID，在账号信息页里。

## 开哪家都可以两家并用

主业务放一家、备份和灾备放另一家，并不少见。两家的办理入口分别是 [阿里云国际开户与充值](https://www.clouddage.com/platforms/alibaba-cloud) 和 [腾讯云国际开户与充值](https://www.clouddage.com/platforms/tencent-cloud)，页面上写了各自要准备什么、交付什么。
