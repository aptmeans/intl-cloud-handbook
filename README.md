## 速查

**五个平台充值时认的账号标识**

| 平台 | 标识 |
| :--- | :--- |
| 阿里云国际 | UID（账号 ID） |
| 腾讯云国际 | 账号 ID |
| AWS | AWS 登录账号 |
| Azure | 订阅信息 |
| Google Cloud | 结算账户信息 |

**USDT 转账前看四项**：收款网络、收款地址、应付金额、付款有效期，都以订单页为准。

**拿到新账号先做三件事**：改密码、开 MFA、建子用户。
